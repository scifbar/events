# Contributing to an event write-up

Each event has an open feedback period before its write-up is finalized and published. A deadline
is announced when the draft is shared; after that, the organizer finalizes and publishes it.

**If you have a GitHub account:**
- Open the file on GitHub and click the pencil ("Edit this file"). This forks the repo and opens
  a pull request for you automatically - no local git required.
- Or fork, branch, and open a pull request the usual way if you're comfortable with git.

**If you don't have a GitHub account:**
- Reply by email to nikolai@scifbar.dk, or comment on the shared Google Doc, with your suggested
  change and which section it applies to.

All suggestions are reviewed by the organizer and merged at their discretion before the deadline.
